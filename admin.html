Khi bạn dán mã GitHub Token (chỉ cần làm 1 lần duy nhất), mỗi lần bấm "💾 LƯU & ĐỒNG BỘ LÊN WEB NGAY", hệ thống sẽ tự động cập nhật thẳng file data.json lên GitHub để mọi điện thoại và máy tính đều thấy thay đổi ngay lập tức!
